# Save exact recovered-pocket draft operations

This pilot extends `solidworks_cam_document_lifecycle` with the same explicit `feature_kind="autodetected_pocket"` authority used by [selected GOP](cam-recovered-pocket-gop.md). Use `machine_kind="mill_single_feature_qualification"` and `action="prepare"` or `action="save"`. The extension does not expose a new endpoint or alter legacy open/circular lifecycle contracts. Close is outside this authority.

Supply the current document/source SHA, owned PID, actual selected feature ID and the exact nonempty ordered `expected_operation_native_ids`. Retain `acknowledge_qualification_copy=true` and `message_policy="vendor_default"`. In addition to the recovery and prior zero-operation Save receipt paths/hashes, supply `definition_gop_receipt_path` and `definition_gop_receipt_sha256` for the completed selected GOP.

The file-only GOP verifier requires a successful RETAIN1 receipt, strict integer HRESULT zero, three complete recorded captures, exact recovery/Save source binding, sole selected-feature operation links, generic tool identities and zero toolpath records. It checks the consumed per-feature marker and preserves the original uncertain creator. A pre-existing operation setup must retain its ID and metadata; only its operation count may change. A fresh receipt name never authorizes another GOP.

Prepare reads the full current feature/operation/tool state and checks it against the pinned GOP after-state. Save requires that fresh prepared hash and a new output receipt. The existing lifecycle invokes `ICWApp.SaveActiveDocument` once. When strict integer zero returns, the raw result and newly observed saved-file SHA are written to the receipt before later event or geometry-readback checks. A failure after that point retains these facts and never causes automatic replay.

All capture handles close before Save. Only the current target source pin may change, through the explicitly observed native Save transition. Historical recovery, prior Save, GOP, marker, protected original and geometry/code evidence remain unchanged. The post-save capture must retain exact operation IDs/order/types, setup IDs, feature links, path counts, generic tool observations, feature header, analytic sketch and reviewed Attribute suffix. The document must be clean after successful readback. No GTP, GOP, import, explicit rebuild, stock/tool setter or close occurs.

`save_readback_verified` is not persistence after reopen. Island contours, attribute payload/feature association, physical depth, stock, cutter/holder clearance, cutting recipe and production remain unqualified. The module does not skip the explicit Save merely because the current CAD dirty flag is false. Software tests and static public API evidence are separate from live qualification.
