# CAM 浅导向槽批处理（pilot）

本功能沿用已验证的原生 MILL 接口，限定为两个已绑定特征、每个特征一项粗加工和一项精加工。
它不是任意文档、任意特征的通用生成器。输入包含明确的进程、文档、配置和证据摘要。

## 创建定义

`solidworks_cam_insert_shallow_guide_definitions` 在一次受控会话中顺序插入四项定义。
默认工艺名称和 ID 必须来自当前原生目录；每次插入记录实际返回 ID，检查新定义的 NC
可读性，以及原有操作元数据和轨迹记录数。任何不确定结果立即停止，不自动重放。

该调用不设置刀具、不生成轨迹、不保存文档。成功仅表示四项定义存在于当前会话内存，
不表示其默认刀具、切削条件或几何轨迹已经合格。必须保存并另行验证持久化。

## 一次读取四项参数

`solidworks_cam_read_guide_parameters` 接受 `process_id`、`request_path`、`request_sha256`。
签封请求引用成功的四定义回执，并固定原文档及配置；不接受部分成功作为后续依据。

读取内容包括粗加工入口、切深和余量；精加工侧向/深度参数、引入引出和防过切选项；
NC、平面以及已分配刀具的尺寸。共享刀具只读取一次，随后复用同一读数。
读取前后比较原有操作，保持源文件字节不变，不调用 setter、GTP 或 Save。

完整的参数读取不等于制造单位、物理刀具、夹具、机床和切削条件已经合格。
原生返回的默认设置必须单独审查；不能把创建成功等同于可立即计算或投产。

## 失败和恢复

失败前没有原生写入时，保留原回执、核对零写入证据和源文件，修正代码后使用新输出。
已经尝试写入时禁止盲目重复。先根据实际返回 ID、状态和只读快照核实部分结果。
创建或读取的报告不代替独立保存与重新读取的持久化证据。

## 已验证范围

在 SOLIDWORKS/CAM 2026 的一个受控实例上，四项原生定义及其最小 NC 均读取成功；
四项完整参数读取也成功，并确认原九项操作元数据和六条既有轨迹记录数保持不变。
没有在本功能中比较 CL 字节、生成新轨迹或给出生产许可。

离线回归：定义及恢复边界 36 项，参数读取及 MCP 包装 32 项。
包含真实读取包构造链的离线测试；模拟测试和实际 CAD 验证明确区分。
其他 SOLIDWORKS 版本尚未验证。
