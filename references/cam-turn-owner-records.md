# TURN records on the CAM owner STA

This pilot adds an optional `record_read` selection to the existing `ICamBatchReader.ReadTurnSnapshot` JSON request. The COM interface GUID, method and binary ABI remain unchanged. The new MCP endpoint is `solidworks_cam_read_turn_owner_records`. Native qualification is pending; compilation and fixture tests do not demonstrate CAM record access.

The caller pins the saved clean part, process lifetime, loaded host DLL/TLB/MVID and CAM typelib. Existing owner-thread dispatch, configuration binding and full operation inventory are reused. Record mode requires one selected generated FACE operation (type 7 or 8), one path, an exact expected count from 1 through 256 and exact operation, feature, setup and position IDs. It skips tool and NC scalar observation. No operation index is inferred from a native ID.

On the owner STA the reader calls public `ICWToolpath.GetEnumRecords` once, QIs `ICWDispatchCollection`, verifies Count, then reads Item from zero through Count−1. This collection convention is supported by the saved official ToolPath and CL Record Info walkthrough. Each record retains its original index and raw type. Only GOTO type 7 is decoded with `ICWGotoRecord.GetRapidLine`, `GetToolpathPoint` and `ICWPosition.GetCoordinates`. The raw rapid integer is not relabelled as a Boolean. Unknown record payloads and all tool vectors remain unread. This is not a complete CL clone and does not establish units, frame, machining safety or mutability.

The first native exception stops enumeration and preserves its stage, partial rows and HRESULT. There is no indexed-access, remote-Python or alternate-QI fallback. Post-read collection/path counts, full inventory, document identity/configuration/clean state, process lifetime, source/binary hashes, runtime sources and event disconnection are checked. A failure cannot become a verified record observation. Native exceptions can return the last attempted stage; a process crash can leave only the outer pending receipt, so it must never be retried automatically.

The historical external `GetRecordAtIndex` and `GetEnumRecords` failures with 0x80040201 remain preserved and the old remote route stays disabled. The only changed input for this qualification is a reviewed in-process owner-STA execution context, not an assertion that it will succeed. The API exposes no setters, GTP, Save or export. Loading/replacing the host is a separate explicit deployment action; do not overwrite a loaded DLL or touch another CAD session.

Request fields are the existing in-process snapshot fields plus `record_read`, `cam_typelib_path`, `cam_typelib_sha256`, `qualification_only=true` and `message_policy=vendor_default`. NC IDs must be empty and the legacy reference receipt must be null. A fresh receipt is mandatory. The returned `host_response.record_read.records` contains all indices/types and decoded GOTO positions, with limitations kept false until independent exported-CL/frame review.
