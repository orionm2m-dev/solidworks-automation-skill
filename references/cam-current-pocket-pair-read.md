# Current saved pocket pair parameter reader

Pilot endpoint `solidworks_cam_read_current_pocket_pair_parameters` reads exactly one ungenerated Rough/Contour pair in a clean saved one-feature plan. Authority is the successful definition recovery, zero-operation Save, selected GOP and explicit post-GOP Save. Original uncertain creator evidence remains immutable.

Inputs bind PID/lifetime, exact part/source, actual feature and ordered operation IDs, four receipt path/SHA pairs and a fresh output path. The server requires the selected process and its ordinary operation lock; authority is prepared once and consumed once.

Before and after, existing definition capture checks current configuration, feature/header, full two-operation inventory and analytic sketch/body invariants. One guarded parameter pass reuses `sw_cam_mill_current_parameters.capture_rows`, existing NC feed/clearance/rapid readers, twenty Finish fields, protected Finish settings and lead details. Full scalar cutter/holder dimensions are cached once per distinct tool. Generic assignment IDs are rechecked per consumer. No old route is enumerated.

Outputs preserve raw numeric/enum values, effective setup-versus-operation plane selection and diagnostics. Native units, physical depth, feeds for304L, exact cutting/holder profiles, island association, collision clearance and machining acceptance remain unqualified. Plane pointer getters use the existing public wrapper with owned initialized output storage and strict HRESULT0. No setter, tool factory/assignment, GOP/GTP, import, explicit rebuild or Save is reachable.

Any source/identity/inventory change, native exception, event or cleanup failure rejects acceptance; partial observations remain recorded. No automatic retries. A scoped native invocation completed with 357 parameter getter observations, unchanged source/inventory/runtime and clean event cleanup. This qualifies the bounded read route only; it does not qualify numerical units, physical cutter profiles or machining. Project-specific receipt pins remain external evidence.
