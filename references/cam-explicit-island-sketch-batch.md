# Four explicit island sketches

`solidworks_cam_create_explicit_island_sketches` is a pilot batch for an explicitly named exclusive byte-copy of an initialized empty MILL part. It consumes pinned copy and four-footprint plans, exact PID/lifetime, CAD/CAM configuration and setup identity/frame. Public typed metadata is checked before acquiring the application. Native qualification of this batch remains pending.

The existing signed mixed-profile component creates exactly four closed two-arc/two-line sketches. It retains actual model-to-sketch transforms, endpoint/midpoint/radius/length observations and signed minor-arc evidence. Each mutation has a durable target-only once marker; an uncertain action cannot be retried by changing the report or recipe.

One initial complete CAD/CAM snapshot and a complete empty CAM check after each sketch protect the copied setup. All existing CAD features, reference planes and solid-body fingerprints remain protected. Only the recorded new plane/sketch nodes and dirty flag may change. The existing mass-property comparison uses relative tolerance 1e-10, while native entity geometry uses the existing 1e-8 metre readback tolerance. No underlying untrimmed curve interval is substituted for an observed arc.

`save_after_creation` is a required strict Boolean. If true, a fresh complete four-sketch observation serves both final creation verification and Save-before evidence. One `ICWApp.SaveActiveDocument` is followed by a fresh complete Save-after observation. Raw return and the new source hash are retained immediately. Source handles are closed before Save; only the copy's source pin advances. The original source and immutable input files remain protected. Each full snapshot is stored unchanged; the Save comparator normalizes only source/dirty fields, already-proved mass-property noise, and maps independently verified raw sketch observations to their identical explicit specifications. If false, no Save is attempted and the result explicitly remains unsaved.

The receipt contains `before`, four component `sketches`, `after`, `initial_pins`, `current_pins`, action journal, events and cleanup identity. With Save it also contains full `save_snapshots.before/after`, the original checked `native_save` report and `source_transition`. Final acceptance requires all five scoped flags and zero events after disconnection. Later errors revoke scoped acceptance while preserving actual Save facts.

No CAM feature or island is created here. Outer-circle creation is a separate existing action. There is no import, explicit rebuild, GOP, GTP, tool or stock mutation, UI automation, rollback or retry. A projection plane is a caller-specified sketch plane, not a measured island start height. CAM association, physical island depth, machining suitability and reopen persistence remain false.
