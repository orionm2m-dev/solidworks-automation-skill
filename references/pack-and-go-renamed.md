# 显式命名的原生 Pack and Go（pilot）

`solidworks_pack_and_go_renamed` 接收 UTF-8 JSON 映射文件：`[{"source":"绝对源路径","target":"绝对目标路径"}]`。必须提供 `expected_document_path`，默认 `dry_run=true`。原生 Pack and Go 的完整列表必须与映射一一对应；不允许缺项、重复目标、覆盖文件、改变扩展名或原地重命名。工具不保存、关闭或丢弃源文档，不以文件复制替代原生链接改写。

写入通过安装目录发现的 SOLIDWORKS PIA，在 MCP 操作互斥锁持有期间调用固定的 C# 后端。后端只绑定调用者确认的 PID，并在写入前后检查活动文档路径；没有全局实例或启动回退。数据通过 Base64 JSON 参数传递，不拼接执行代码，不暴露任意脚本入口。

结果保留源文件哈希、脏状态、组件路径/变换、体积、原生保存状态及输出哈希。`ready` 只说明枚举和映射通过；`copied` 仍要求关闭新文档后冷开、核对组件引用/位置/体积及外观，不能据文件存在宣称链接正确。含未保存修改的源文档不会自动保存，其复制内容需单独核验。

验证环境：Windows、SOLIDWORKS 2026 SP4.1（34.4.1）、Python 3.10.11。八文档、七组件的装配体映射通过原生 Pack and Go 写入，保存状态全为 0，源文件哈希不变；其他版本尚未实机验证。Python 动态调用 GetPackAndGo 在该环境报参数必需，PIA 路线通过；工具能力保持 pilot。
