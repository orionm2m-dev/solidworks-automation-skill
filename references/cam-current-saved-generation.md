# Current saved selected MILL generation

The existing `solidworks_cam_generate_configured_local_group` endpoint has an explicit sealed-packet `generation_mode="current_saved"` branch. The historical four-operation branch remains unchanged. This staged branch has no native qualification yet.

Its authority is a completed, verified current-saved parameter-batch configuration and checked Save. The actual postconfiguration source SHA, process lifetime, complete ordered operation inventory, explicit selected Rough-operation IDs, own parameters and full collected tool scalars are pinned. A canonical binding digest is distinguished from immutable evidence-file hashes. The scope remains an observed three-step compound feature and its Rough/Finish parameter pair; it is not an arbitrary-feature generator.

A completed explicit `recover_save` parameter-batch receipt is also accepted. Its original request, reviewed prepare, partial action receipt and consumed marker remain immutable and are rechecked throughout the generation session. The shared history validator must establish every original setter outcome and the exact final captured state. Recovery must contain exactly one verified Save and no replayed setter; fresh before/after captures must match that original final state, and the saved captures may differ only by the clean flag. A partial receipt, recovery prepare, unknown Save result or ordinary apply relabelled as recovery is rejected. This generation branch does not perform recovery itself.

One event/mutex session exports pre-generation machine CL, generates only the explicit ungenerated Rough subset once, verifies the full captured delta, performs one checked Save, then exports saved machine CL. The old generated blocks must have unique unchanged complete command/motion/circle signatures in their original order. The native record count is observed, never predicted; it is not a motion count. CL exports cover the whole machine, not only the selected operation.

Suppressed operations are permitted only when their complete source rows are pinned as suppressed, ungenerated and empty and remain exactly unchanged. They are never dispatched. The default legacy CL validator remains strict. Existing bounds remain 32 operation rows and 100000 total native records; exceeding a bound stops without truncation.

Only selected generated flags/counts and a strict Boolean document dirty flag may change at GTP. The complete captured parameter/tool/profile/setup context is protected. Save requires the established typed integer-zero return, then source-hash transition, clean document and equal saved captures. A false initial dirty flag does not waive Save. Events, unexpected values, changed context, partial outcomes and runtime drift stop the packet and preserve actual returned evidence and its durable once marker. There is no replay, rollback, Save after failure, whole-machine GTP, setter or tool assignment.

Programmatic checks do not qualify physical units, setup transforms, cutter program point, stock, machining coverage, collision clearance or production. A parsed CL does not establish arc sweep or a full circle from endpoints alone. Saved-file checks do not claim reopen persistence.
