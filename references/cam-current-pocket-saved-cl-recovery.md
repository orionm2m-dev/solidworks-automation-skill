# Export an already saved generated pocket

`solidworks_cam_export_saved_current_pocket` is a pilot CL-only continuation after one native Save returned strict int0, changed the target source and completed exact before/after captures, but local evidence deduplication failed while building the context payload. The original failure stays immutable and uncertain. This endpoint invokes no Save, parameter/tool setter, GOP, GTP, import, rebuild or UI action.

The request binds process/lifetime, document/current source hash, feature and ordered operation IDs, the pinned completed-Save attempt, and fresh CL/report paths. The historical predecessor validator retains all durable checks from the existing current-context loader. It explicitly keeps the recorded old target hash historical, verifies immutable evidence, and does not pretend that old hash is still live. A separate pure finalizer validates the actual Save return, normalized before/after observations, changed hash and exact predecessor pin before replacing only the mutable target pin. Every remaining pin is retained and checked. Deduplication validates both bounded input lists before enforcing the unique-pin limit.

The endpoint then reuses the existing export implementation with exactly two complete fresh captures: CL-before must equal the recovered saved state; CL-after must equal CL-before. A target/source-specific durable marker permits one export attempt. Strict int0, exclusive output directory, pinned file bytes, parser/native record count and selected operation binding are required. Native returns, partial captures and produced files remain diagnostic evidence on any later failure; no automatic retry occurs.

The receipt separates historical Save facts from this call: `historical_model_saved` and `historical_save_readback_verified` preserve the prior successful Save; `Save_attempted=false` and `model_saved=false` truthfully mean that this endpoint does not save. Complete fresh success sets `saved_generation_context_verified` and `current_context_verified`. The payload scope remains `CURRENT_GENERATED_POCKET_CONTEXT_V1`, which the old GTP-false loader rejects. No historical uncertain status or false runtime flag is rewritten.

Feeds, feed-change cause, units, actual tool seating, CL/world mapping, guide/stock sweep, material removal, production and reopen persistence remain unqualified. The output is raw CL evidence for a separate geometry review. Native execution of this CL-only endpoint is pending.
