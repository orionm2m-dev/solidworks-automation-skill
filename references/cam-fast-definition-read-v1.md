This separate version preserves the existing complete definition payload. It acquires the real CAM application, document and machine once under the ordinary process/document/source/event guard. The unchanged prebound inventory extraction and existing feature-header reader then traverse only that retained graph using fixed getter/interface allowlists, a shared 4096 read/QI budget, per-getter event checks and strong entry/exit checks. There is no substitute ActiveDoc implementation.

The original body, raw feature tree and analytic circle verification block is executed before and after the retained reads. Both observations must match the immutable baseline and each other, with the existing narrow body mass tolerance. Configuration, setup membership, feature identity/header, complete output fields and returned native-root names retain exact source AST parity. Two strong guards retain all explicit evidence with a fixed 128-pin capacity; the final ordinary boundary rechecks process/lifetime/document/dirty identity and file contents.

The caller must supply genuine current authority and pin this new module, the unchanged definition_capture_v2 module, prebound inventory module, its underlying sw_cam_process_import parent, and the existing retained read guard. The underlying inventory parent is an explicit new dependency; historical receipts are not relabelled as having pinned it. The full original authority list must remain present.

This changes observation timing: global active-document and file metadata checks are not performed for every retained CAM getter. It is not an atomic snapshot or write lease, and transient external A-to-B-to-A changes are not excluded. Getters and QueryInterface retain their returned child objects; foreign owners, unapproved methods/interfaces, boolean indices and budget overruns invalidate the scope. A failure leaves the top-level capture_complete false.

Offline evidence: 26 tests cover complete payload and inventory/header trace parity, unchanged frozen source dependencies, two CAD checks, late body/tree/circle/source/evidence/PID/lifetime/dirty/event failures, mandatory dependencies, child-interface retention, foreign roots, global/mutating getter rejection and shared read/QI budgets. Native parity and speed remain unqualified. Timings distinguish before_cad, bootstrap, inventory_and_header and after_cad. There is no setter/Save/GTP/export provider or MCP endpoint in this package. It is not integrated into the frozen retained pair adapter or any active recovery. A separately authorized read-only probe must compare the actual saved context and collect timings before adoption.
